### 담당 영역 및 주요 기능 개발

주로 배송·주문 처리 영역을 담당하며, WinForms 기반 데스크톱 애플리케이션에서 대량 데이터 처리·시각화·연동 기능을 개발했습니다.

- **주문·배송 처리 로직 개발**: 주문 수집 로직 개선, 주문 상태 변경·확인 처리·발주 처리 등 핵심 배송 업무 기능 개발
- **대량 데이터 엑셀 일괄 처리**: 주문 목록을 엑셀로 일괄 다운로드하고, 송장 정보를 입력한 엑셀을 재업로드하여 일괄 반영하는 기능 구현
- **데이터 시각화·통계 화면 개발**: 접속 현황·통계를 차트(파이/도넛)와 데이터 그리드로 시각화하고, 검색·필터·엑셀 추출이 가능한 관리 화면 개발 (Infragistics 활용)
- **시스템 간 연동**: 솔루션에서 처리한 고객 문의 답변을 각 마켓 관리자 사이트로 전송하는 연동 기능 개발
- **데스크톱 앱 배포·호환성 대응**: 엑셀 호환성 이슈 대응을 위해 고객 PC 환경을 추적하고 .NET 2.0 환경에 맞춰 설정을 조정하는 등, 현장 배포 환경의 문제를 진단·해결

### 주요 개선 작업

**1. 11번가 주문수집 모듈 리팩토링 (HTML 파싱 → JSON API)** [2017.09 ~ 2017.10]
- 문제: HTML 파싱 방식의 주문 수집 모듈이 11번가 사이트 구조 변경 시마다 장애 발생, 운영 부담 가중
- 해결: JSON 기반 API 호출 구조로 모듈 전면 재설계
- 결과: 사이트 구조 변경에 따른 장애 빈도 감소, 데이터 파싱 안정성 향상

**2. 카페24 주문 관리 크롤링 → 공식 API 전환** [2021.01 ~ 2021.03]
- 문제: 크롤링 기반 주문 수집의 차단·오류 리스크 및 유지보수 비용 증가
- 해결: 카페24 공식 Open API 기반으로 주문 수집 구조 재구성
- 결과: 안정성과 데이터 정확도 향상, 차단 리스크 제거

**3. 클라이언트 동시접속 제한 및 REST API 신규 개발** [2019.04 ~ 2019.11]
- 라이선스 정책에 따른 한 계정 동시접속 제한 기능 설계 및 구현
  · 커넥션 풀에서 접속 계정 정보를 관리하여, 동일 계정이 다른 PC에서 접속을 시도하면 차단하는 세션 제어 구조 구현
- 외부 연동을 위한 REST API 신규 구축, 기존 WCF SOAP 중심 구조에서 REST 기반으로 확장하는 기반 마련
- 크롤링 연동의 로그인 세션 유지 기능을 추가하여 수집 안정성 향상

**4. 솔루션 .NET Framework 버전 업그레이드 (2.0 → 4.6)** [2020.02 ~ 2020.04]
- 레거시 라이브러리 의존성 검토 및 호환성 이슈 해결
- async/await 등 신규 .NET 기능 활용 가능 환경 마련, 보안 패치 수령 가능 상태로 전환

**5. 배송관리 서버 IDC 이전 작업 (온프레미스 인프라 운영)**
- 배경: 배송관리 서버의 하드웨어 문제로 서버 이전이 필요한 상황
- 사전 작업: 이전 대상 서버에 Windows 업데이트, DB 설치 및 메모리 설정, 계정 생성, 웹서비스 이전, 방화벽 설정 등 수행
- 당일 작업: 서비스 영향을 최소화하기 위해 사용률이 낮은 일요일 야간을 선택, IDC 직접 방문하여 기존 DB 백업 및 신규 서버로 파일 이전 후 서비스 정상화 마무리
- 의미: 온프레미스 서버 구성·이전을 직접 수행하며 DB·웹서비스·네트워크 설정 전반을 다룬 인프라 운영 경험

### 프로젝트 4. 감별마켓 — 카페24 입점 마켓 연동 구조 전환

**문제**: 입점 마켓 100여 개의 상품을 네이버 스마트스토어 기반으로 관리 → 확장성 한계
**해결**: 카페24 기반 상품 등록 구조로 전환 및 회원·데이터 통합

**주요 작업**
- 기존 회원 ↔ 카페24 회원 연동 구조 설계
- 상품, 마켓, 포인트 등 도메인 데이터 호환성 확보 및 마이그레이션
- **카페24 Open API rate limit 안정화**
  · 문제: 카페24 호출량이 limit 정책에 근접해 호출 실패 및 데이터 동기화 지연 발생
  · 해결: Redis + Lua 스크립트로 atomic한 호출 카운터 및 delay 로직 구현
  · 결과: rate limit 초과로 인한 호출 실패 제거, 데이터 동기화 안정성 확보
